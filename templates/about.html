ABOUT THE PROJECT

Built for TB screening research

Objective

The PulmoSight project explores how chest radiograph screening can be accelerated through preprocessing and deep learning classification in a compact research workflow.

Architecture

The application combines a robust data ingestion layer with a MobileNet-based classifier and a GA-driven threshold optimization component.

Limitations

This interface is a demonstration and decision-support prototype. It is not a replacement for diagnostic imaging interpretation by qualified clinicians.
